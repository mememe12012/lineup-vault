# Microsoft Store 등록 정보 (Partner Center에 붙여 넣기)

## 앱 이름
라인업 보관함

## 짧은 설명 (Short description)
발로란트 라인업을 스크린샷 3장으로 저장하고, 맵·요원별로 빠르게 찾아보는 PC 앱

## 설명 (Description)
게임 중에 "그 스모크 어디서 던졌더라?" 하고 영상을 다시 찾아본 적 있나요?
라인업 보관함은 내가 찾은 라인업을 스크린샷 3장(서는 곳, 조준점, 결과)으로 저장해 두는 앱이에요.

• 맵과 요원, 공격·수비로 골라서 바로 찾기
• 스크린샷을 끌어다 놓거나 붙여 넣기로 저장
• 자주 쓰는 라인업에 별표
• 파일로 내보내 친구와 주고받기
• 회원가입 없음, 광고 없음, 기록은 내 PC에만 저장

※ Riot Games와 관계없는 개인 제작 앱이에요. VALORANT는 Riot Games의 상표예요.

## 스크린샷
1366×768 이상 PNG 1~10장. 앱에 예시 라인업을 몇 개 넣고 메인 화면, 라인업 상세, 맵 필터 화면을 찍어요.
게임 화면을 그대로 쓰면 Riot의 팬 콘텐츠 정책 안에서만 써요(상업적 이용 금지, 앱은 무료라 괜찮아요).
